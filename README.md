# VoxelMotion SDK - Lite Version

**Free 3D Motion Extraction Tool for Unity**

![Unity](https://img.shields.io/badge/Unity-2022.3+-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 🚀 What is this?
VoxelMotion Lite is a free, limited version of a 3D motion extraction SDK. It detects moving objects in 3D grids and outputs displacement vectors—perfect for physics debugging and QA automation.

## ⚠️ Lite Version Limitation
- **Grid Size:** This free version is strictly limited to **10x10x10** voxels.
- For larger grids and full features, purchase the Pro version.

## ⬇️ Download
Click the **"Releases"** section on the right side of this page to download the latest `voxel_motion_extractor.exe` file.

## 🛠️ How to Use
1. Drag `VoxelMotionBridge.cs` into your Unity `Assets/Scripts` folder.
2. Place `voxel_motion_extractor.exe` in your `Assets/StreamingAssets` folder.
3. Call the bridge from your C# script.
